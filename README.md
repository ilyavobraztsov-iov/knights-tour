# Ход Конём! / Knight's Tour

Шахматная головоломка — PWA для Android и iOS.

## Описание

Классическая задача о туре коня в современном мобильном исполнении.  
Проведите коня по всем клеткам доски, побывав на каждой ровно один раз.

**9 этапов** от 5×5 до 10×10 · Умная подсказка · Звуки · Офлайн

| Этап | Поле | Животное | Замкнутый тур |
|------|------|----------|---------------|
| 1 | 5×5 | 🐣 Цыплёнок | — |
| 2 | 5×6 | 🐱 Котёнок | — |
| 3 | 6×6 | 🦊 Лисёнок | ✓ |
| 4 | 6×7 | 🐺 Волк | ✓ |
| 5 | 7×7 | 🦁 Лев | ✓ |
| 6 | 7×8 | 🐯 Тигр | ✓ |
| 7 | 8×8 | 🦅 Орёл | ✓ |
| 8 | 9×9 | 🐉 Дракон | ✓ |
| 9 | 10×10 | 👑 Король | ✓ |

## Установка на Android

1. Загрузите репозиторий на GitHub
2. Включите **GitHub Pages** (Settings → Pages → main / root)
3. Вставьте полученный URL на [pwabuilder.com](https://pwabuilder.com)
4. Скачайте APK → установите на телефон

## Файлы

```
index.html       — игра (все ресурсы встроены)
manifest.json    — PWA манифест
sw.js            — Service Worker (офлайн кэш)
icon-192.png     — иконка 192×192
icon-512.png     — иконка 512×512
screenshot-*.jpg — скриншоты 1920×1080
```

## Технологии

- HTML5 / CSS3 / Vanilla JS
- Web Audio API (22 звуковых трека)
- PWA: Service Worker + Web App Manifest
- Алгоритм подсказки: Варнсдорф
- Локализация: RU / EN
